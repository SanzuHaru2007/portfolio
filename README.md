# 🚀 Project Manager Bot

Персональный Telegram-бот для удобного учета проектов, отслеживания их статусов и закрепления используемых навыков. 

![Приветствие бота](images/start.png)

---

## 🛠 Технологический стек

* **Язык:** Python
* **Библиотека бота:** `pyTelegramBotAPI` (`telebot`)
* **База данных:** SQLite 3

---

## 📌 Основные функции

* ➕ **Создание проектов (`/new_project`)** — пошаговый мастер для добавления названия, ссылки и текущего статуса.
* 📂 **Просмотр списка проектов (`/projects`)** — отображение всех ваших проектов с удобными кнопками быстрых деталей.
* 🎯 **Управление навыками (`/skills`)** — возможность привязать используемые технологии (*Python, SQL, API и др.*) к конкретным проектам.
* ✏️ **Редактирование (`/update_projects`)** — изменение названия, описания, ссылки или статуса любого проекта.
* 🗑 **Удаление (`/delete`)** — безвозвратное удаление ненужного проекта из базы данных.
* 🔍 **Быстрый поиск** — просто отправьте название проекта в чат, чтобы получить всю информацию о нём!

## ⚙️ Установка и запуск

Подробная инструкция по запуску бота на вашем компьютере:

**1. Клонирование репозитория**  
Скачайте проект к себе на ПК:
> `git clone https://github.com/SanzuHaru2007/portfolio.git`  
> `cd portfolio`

**2. Установка зависимостей**  
Установите библиотеку для работы с Telegram API:
> `pip install pyTelegramBotAPI`

**3. Настройка конфигурации**  
В корневой папке проекта создайте файл `config.py` со следующим содержимым:
* `TOKEN` = `'ВАШ_ТОКЕН_БОТА'`
* `DATABASE` = `'portfolio.db'`

**4. Запуск бота**  
Запустите главный файл программы:
> `python main.py`

*✨ Готово! Бот начнет работу и будет готов к приему команд в Telegram.*
